# shiftcron

Shift timestamps and cron durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/shiftcron/

## Install / run

```bash
git clone https://github.com/theworker02/shiftcron.git
cd shiftcron
node src/cli.js
node --test
```
